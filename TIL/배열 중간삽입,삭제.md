# Java 배열 주요 알고리즘: 삽입과 삭제 (Insert & Delete)

배열은 선언 시 크기가 고정되므로, 리스트(List)처럼 자유롭게 크기를 늘리거나 줄일 수 없습니다. 따라서 데이터를 중간에 삽입하거나 삭제하기 위해서는 \*\*'데이터 이동(Shifting)'\*\*과 **'새로운 배열 복사(Resizing)'** 과정을 거쳐야 합니다.

-----

## 1\. 데이터 삽입 (Array Insert)

데이터를 중간에 삽입하기 위해서는 기존 데이터를 뒤로 한 칸씩 밀어내어(Right Shift) 자리를 확보해야 합니다.

### **핵심 로직 흐름**

1.  **배열 생성**: 기존 배열보다 크기가 1 큰 새로운 배열(`temp`)을 생성합니다.
2.  **데이터 복사**: 기존 데이터를 `temp`로 모두 복사합니다.
3.  **데이터 이동 (Right Shift)**: 삽입할 인덱스(`targetIndex`)부터 끝까지의 데이터를 뒤로 한 칸씩 이동시킵니다.
4.  **데이터 삽입**: 확보된 `targetIndex` 위치에 새로운 값을 할당합니다.
5.  **주소 변경**: `numbers` 참조 변수가 새로운 배열 `temp`를 가리키게 합니다.

### **상세 코드 및 분석**

```java
package chap1_2.array;

import java.util.Arrays;

// 데이터 원하는 위치에 삽입하기
public class ArrayInsert {

    public static void main(String[] args) {

        int[] numbers = {10, 50, 90, 100, 150};

        int targetIndex = 2; // 삽입할 위치 (인덱스 2)
        int newNumber = 70;  // 삽입할 값

        /*
            [데이터 이동 시각화]
            먼저 사이즈가 1개 큰 새 배열부터 생성
            Step 1. [10, 50, 90, 100, 150, 0]   -> 사이즈 증가
            Step 2. [10, 50, 90, 100, 150, 150] -> 끝에서부터 밀기 시작
            Step 3. [10, 50, 90, 100, 100, 150]
            Step 4. [10, 50, 90, 90, 100, 150]  -> targetIndex까지 이동 완료
            Step 5. [10, 50, 70, 90, 100, 150]  -> 빈 자리에 값 할당
         */

        // 1. 사이즈가 1칸 큰 배열 생성
        // 배열은 생성 후 크기 변경이 불가능하므로, 더 큰 배열을 새로 만들어야 함
        int[] temp = new int[numbers.length + 1];

        // 2. 기존 데이터 새 배열로 복사
        for (int i = 0; i < numbers.length; i++) {
            temp[i] = numbers[i];
        }

        // 3. 데이터 뒤로 밀기 (Right Shift)
        // 중요: 뒤에서부터 앞으로 이동해야 데이터가 덮어씌워지지 않음
        for (int i = numbers.length; i > targetIndex; i--) {
            temp[i] = temp[i - 1];
        }

        // 4. 타겟 인덱스에 새 데이터 할당 및 주소 변경
        temp[targetIndex] = newNumber;
        numbers = temp; // 기존 numbers를 버리고 새 배열을 참조

        System.out.println(Arrays.toString(temp));
    }
}
```

## 2\. 데이터 삭제 (Array Delete)

데이터를 삭제할 때는 삭제할 위치 뒤의 데이터들을 앞으로 한 칸씩 당겨와서(Left Shift) 덮어씌운 후, 배열의 크기를 줄입니다.

### **핵심 로직 흐름**

1.  **데이터 덮어쓰기 (Left Shift)**: 삭제할 인덱스(`targetIndex`)를 기준으로, 뒤에 있는 값들을 앞칸으로 당겨옵니다.
2.  **마지막 데이터 처리**: 이동이 끝나면 마지막 칸에는 이전 데이터가 중복되어 남아있게 됩니다 (논리적으로는 삭제됨).
3.  **배열 축소**: 실제 배열의 크기를 줄이기 위해 크기가 1 작은 새로운 배열(`temp`)을 생성합니다.
4.  **데이터 복사**: 유효한 데이터만 `temp`로 복사합니다.

### **상세 코드 및 분석**

```java
package chap1_2.array;

import java.util.Arrays;

// 배열 원하는 위치 삭제 알고리즘
public class ArrayDelete {

    public static void main(String[] args) {

        int[] numbers = {1, 3, 5, 7, 9, 11};

        int targetIndex = 1; // 삭제할 위치 (인덱스 1 -> 값 3)

        /*
            [데이터 이동 시각화]
            사이즈를 1개 줄이기 전에 해야 할 일 (덮어쓰기)
            Step 0. [1, 3, 5, 7, 9, 11]
            Step 1. [1, 5, 5, 7, 9, 11] -> index 2(5)를 index 1로 이동
            Step 2. [1, 5, 7, 7, 9, 11] -> index 3(7)을 index 2로 이동
            Step 3. [1, 5, 7, 9, 9, 11]
            Step 4. [1, 5, 7, 9, 11, 11] -> 마지막 11은 pop 대상
            Final.  [1, 5, 7, 9, 11]     -> 새 배열로 옮기며 마지막 데이터 제외
         */

        // 1. 삭제를 위한 데이터 이동 (Left Shift)
        // targetIndex부터 시작하여 뒤의 값을 앞으로 당겨옴
        for (int i = targetIndex; i < numbers.length - 1; i++) {
            numbers[i] = numbers[i + 1];
        }

        /* [참고] 반복문 내부 동작 원리
           numbers[1] = numbers[2]; // 3 자리에 5 대입
           numbers[2] = numbers[3]; // 5 자리에 7 대입
           numbers[3] = numbers[4];
           numbers[4] = numbers[5];
        */

        // 2. 사이즈가 1칸 작은 배열 생성
        int[] temp = new int[numbers.length - 1];

        // 3. 기존 데이터 새 배열로 복사 (마지막 중복 데이터 제외됨)
        for (int i = 0; i < temp.length; i++) {
            temp[i] = numbers[i];
        }
        
        // 4. 주소 변경
        numbers = temp;

        System.out.println(Arrays.toString(numbers));
    }
}
```

## **3. 핵심 요약 정리**

배열의 삽입과 삭제는 \*\*'인덱스 조작'\*\*이 핵심입니다. 두 알고리즘의 차이점을 비교해 보세요.

| 구분 | **삽입 (Insert)** | **삭제 (Delete)** |
| :--- | :--- | :--- |
| **목적** | 중간에 새 공간 확보 | 중간의 데이터를 제거 |
| **배열 크기** | `기존 길이 + 1` | `기존 길이 - 1` |
| **이동 방향** | **Right Shift** (뒤로 밀기) | **Left Shift** (앞으로 당기기) |
| **Loop 방향** | **뒤에서 앞으로** (`len` $\rightarrow$ `target`) | **앞에서 뒤로** (`target` $\rightarrow$ `len`) |
| **주의사항** | 뒤에서부터 밀지 않으면 데이터가 덮어씌워져 소실됨 | 마지막 요소 처리를 위해 배열 크기를 줄여서 복사해야 함 |
