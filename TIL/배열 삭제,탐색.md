# Java 배열 알고리즘 정리: 삭제(Pop)와 탐색(Search)

자바의 배열(Array)은 생성 시 \*\*크기가 고정(Fixed Size)\*\*된다는 특징이 있습니다. 따라서 요소를 삭제하거나 크기를 줄이려면 **새로운 배열을 생성하여 데이터를 복사**하는 과정을 거쳐야 합니다.

이 문서에서는 배열의 맨 끝 데이터를 삭제하는 **Pop** 알고리즘과, 데이터를 순차적으로 찾는 **Linear Search(선형 탐색)** 알고리즘을 다룹니다.

-----

## 1\. 배열의 삭제 (Pop)

배열의 맨 끝 데이터를 삭제하는 로직입니다. 자바의 배열은 크기를 동적으로 줄일 수 없으므로, **`기존 크기 - 1`인 새 배열을 만들고 데이터를 옮겨 담는 방식**을 사용합니다.

### 1-1. 핵심 로직 흐름

1.  **백업**: 삭제될 데이터(맨 끝 요소)를 별도 변수에 저장합니다.
2.  **생성**: 기존 배열보다 크기가 1 작은 새로운 배열(`temp`)을 생성합니다.
3.  **복사**: 반복문을 통해 맨 끝 요소를 제외한 나머지 데이터를 새 배열로 복사합니다.
4.  **주소 이전**: 기존 배열 변수(`numbers`)가 새 배열(`temp`)을 가리키도록 참조값을 변경합니다.

### 1-2. 소스 코드 (`ArrayPop.java`)

```java
package chap1_2.array;

import java.util.Arrays;

// 배열 데이터 맨 끝 제거
public class ArrayPop {

    public static void main(String[] args) {

        int[] numbers = {10, 20, 30, 40, 50, 60};

        // pop: 맨 끝 데이터를 지우면서 가져옴
        // 0. 지워질 데이터를 백업
        // (배열의 마지막 인덱스는 항상 length - 1 입니다)
        int delTarget = numbers[numbers.length -1];

        // 1. 기존 사이즈보다 1개 작은 배열 생성
        // (배열은 한 번 생성되면 크기 수정이 불가능하므로 새 배열이 필요함)
        int[] temp = new int[numbers.length -1];

        // 2. 새 배열의 맨 끝 데이터만 빼고 복사
        // (삭제 대상인 마지막 인덱스 전까지만 반복)
        for (int i = 0; i < numbers.length -1; i++) {
            temp[i] = numbers[i];
        }
        
        // 3. 주소값 이전
        // (numbers가 가리키던 과거의 배열(길이 6)은 더 이상 참조되지 않아 GC(Garbage Collector)의 대상이 됨)
        numbers = temp; 
        temp = null; // temp 변수의 역할은 끝났으므로 참조 해제 (선택사항)

        System.out.println(Arrays.toString(numbers));
        System.out.println("삭제된 데이터:" + delTarget);

    }
}
```

## 2\. 배열의 탐색 (Linear Search)

원하는 데이터가 배열의 몇 번 인덱스에 있는지 찾아내는 과정입니다. \*\*선형 탐색(Linear Search)\*\*은 가장 기초적인 탐색 방법으로, 0번 인덱스부터 끝까지 순차적으로 하나씩 비교합니다.

### 2-1. 핵심 로직 흐름

1.  **초기화**: 찾으려는 데이터의 인덱스를 저장할 변수(`index`)를 `-1`로 초기화합니다. (찾지 못했을 경우를 대비)
2.  **순회**: 반복문을 통해 배열의 모든 요소를 하나씩 꺼냅니다.
3.  **비교**: 찾으려는 값(`target`)과 현재 요소가 같은지 확인합니다.
    * **문자열 비교 주의**: `String`은 참조 타입이므로 `==` 연산자가 아닌 **`.equals()` 메서드**를 사용해야 합니다.
4.  **결과**: 데이터를 찾으면 인덱스를 저장하고 반복문을 종료(`break`)합니다.

### 2-2. 소스 코드 (`ArraySearch.java`)

```java
package chap1_2.array;

// 배열 탐색 : 선형(순차) 탐색
public class ArraySearch {

    public static void main(String[] args) {

        // 배열의 인덱스 탐색과 요소 유무 확인
        String[] foods = {"족발","파스타","치킨","삼겹살"};

        String target = "치킨";

        // 선형 탐색: 0번부터 일일히 순차적으로 체크
        int index = -1; // 찾지 못했음을 가정하고 -1로 시작
        for (int i = 0; i < foods.length; i++) {
            // 문자열 비교는 == 이 아니라 equals()를 사용해야 함에 주의!
            if(foods[i].equals(target)){
                index = i;
                break; // 데이터를 찾았으면 불필요한 반복을 멈춤
            }
        }
        // 유무 확인 (인덱스가 -1이 아니면 찾은 것)
        boolean isPresent = index != -1;
        System.out.println("타겟의 인덱스: "+ index);
        System.out.println("타겟의 유무: "+ isPresent);
    }
}
```

### 2-3. 주요 메서드 정리: String 비교

자바에서 문자열을 비교할 때 가장 많이 실수하는 부분이 `==`과 `equals()`의 차이입니다.

| 구분 | 메서드/연산자 | 설명 | 비고 |
| :--- | :--- | :--- | :--- |
| **값 비교** | `str1.equals(str2)` | 두 문자열의 \*\*내용(값)\*\*이 같은지 비교 | **권장**. `true`/`false` 반환 |
| **주소 비교** | `str1 == str2` | 두 문자열 객체의 **메모리 주소**가 같은지 비교 | 내용이 같아도 주소가 다르면 `false`가 나올 수 있음 |
| **배열 출력** | `Arrays.toString(arr)` | 배열의 요소를 `[값1, 값2, ...]` 형태의 문자열로 반환 | 배열 자체를 출력하면 주소값이 나오므로 이 메서드 사용 |

## 3\. 요약

* **배열의 크기 변경**: 불가능하다. 삭제나 추가를 위해서는 \*\*새로운 배열을 생성(`new`)\*\*하고 **데이터를 복사**해야 한다.
* **참조 변수 변경**: `numbers = temp;` 코드는 실제 배열 안의 값을 바꾸는 것이 아니라, `numbers`라는 변수가 가리키는 \*\*주소지(화살표)\*\*를 `temp`가 만든 새 배열로 돌리는 것이다.
* **선형 탐색**: 앞에서부터 하나씩 찾는 방식. 데이터가 많아질수록 속도가 느려질 수 있다.
* **문자열 비교**: 반드시 \*\*`.equals()`\*\*를 사용한다.
