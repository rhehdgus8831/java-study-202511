## 1\. 데이터 타입 (Data Types)

자바는 **정적 타이핑(Static Typing)** 언어입니다. 변수를 선언할 때 반드시 데이터 타입을 명시해야 하며, 컴파일 시점에 타입이 결정됩니다.

### 1.1. 자바의 기본 데이터 타입 (Primitive Types)

기본 타입은 실제 데이터 값을 메모리(Stack)에 저장합니다.

| 종류 | 타입 | 메모리 크기 | 표현 범위 및 특징 |
| :-- | :-- | :-- | :-- |
| **논리형** | `boolean` | 1 byte | `true`, `false` (조건식에 주로 사용) |
| **문자형** | `char` | 2 byte | 유니코드 문자 1개 (예: 'A', '가') |
| **정수형** | `byte` | 1 byte | -128 \~ 127 (이진 데이터 처리에 주로 사용) |
| | `short` | 2 byte | -32,768 \~ 32,767 (C언어 호환용, 잘 안 씀) |
| | `int` | 4 byte | 약 -21억 \~ 21억 (**자바 정수 연산의 기본 단위**) |
| | `long` | 8 byte | `int` 범위를 넘어서는 큰 정수 (접미사 `L` 필요) |
| **실수형** | `float` | 4 byte | 소수점 7자리 정밀도 (접미사 `F` 필요) |
| | `double` | 8 byte | 소수점 15자리 정밀도 (**자바 실수 연산의 기본 단위**) |

> **참고 (Reference Type):** `String`은 기본 타입이 아닌 \*\*참조 타입(클래스)\*\*입니다.

### 1.2. 실습 코드 (`DataType.java`)

```java
package chap1_2;

public class DataType {

    public static void main(String[] args) {

        // 정적 타이핑 언어: 변수 선언 시 타입을 명시해야 함

        // [기본적인 변수 선언과 초기화]
        // 숫자
        int age = 20;
        // 실수
        double pi = 3.14;
        // 한글자 (홑따옴표 사용)
        char c = 'A';
        // 문자열 (쌍따옴표 사용, String은 클래스 타입)
        String greeting = "안녕하세요";
        // 논리값
        boolean flag = true;

        // ---------------------------------------------------------
        // 1. 정수 타입 ( byte: 1, short: 2, int: 4, long: 8 )
        // ---------------------------------------------------------

        // 1byte == 8bit -> 10진수 정수 8 => 0 0001000
        // 범위: -128 ~ 127 ($ -2^7 \sim 2^7-1 $)
        byte b = 127;

        // 2byte == 16bit -> 10진수 정수 100 => 1100100
        // 범위: -32768 ~ 32767
        short s = 32767;

        // int는 약 21억까지 저장 가능
        int i = 2147483647;
        
        // long 타입은 int 범위를 넘을 경우 숫자 뒤에 'L' 또는 'l'을 붙여야 함
        long l = 9223372036854775807L;


        // ---------------------------------------------------------
        // 2. 실수 타입
        // ---------------------------------------------------------

        // float 타입은 리터럴 뒤에 'F' 또는 'f' 필수
        float f1 = 3.123123111F; // float 4byte (정밀도가 낮아 끝부분 잘림 발생 가능)
        double d1 = 3.123123111; // double 8byte (기본 실수 타입)
        
        System.out.println("f1 = " + f1);
        System.out.println("d1 = " + d1);


        // ---------------------------------------------------------
        // 3. 논리 타입
        // ---------------------------------------------------------
        boolean b1 = true;
        boolean b2 = false;
        System.out.println("b1 = " + b1);
        System.out.println("b2 = " + b2);


        // ---------------------------------------------------------
        // 4. 문자 타입
        // ---------------------------------------------------------
        char c1 = 'A'; // 2byte
        char c2 = 44032; // 유니코드 정수값 직접 할당 가능 ('가'의 코드값)
        System.out.println("c2 = " + c2);

        // char 배열을 이용한 문자열 생성 (내부적 원리)
        char[] cArr = {'A', 'B', 'C'};
        String str = new String(cArr);

        System.out.println("str = " + str);

        String str2 = "안녕하세요";

        // [Text Block] 자바 17부터 지원 (여러 줄 문자열)
        // 큰따옴표 3개(""")로 감싸서 사용
        String str3 = """
                안녕
                메롱
                잘가
                """;
    }
}
```

## 2\. 형 변환 (Type Casting)

형 변환이란 데이터의 타입을 다른 타입으로 변경하는 것을 말합니다.

### 2.1. 핵심 개념

1.  **암묵적 형 변환 (Upcasting / Promotion)**

    * **작은 타입 → 큰 타입**으로 이동.
    * 데이터 손실이 없으므로 컴파일러가 자동으로 변환해 줍니다.
    * `byte` → `short` → `int` → `long` → `float` → `double`

2.  **명시적 형 변환 (Downcasting / Demotion)**

    * **큰 타입 → 작은 타입**으로 이동.
    * 데이터 손실이 발생할 수 있으므로 **`(타입)` 연산자**를 사용하여 강제로 변환해야 합니다.

3.  **연산 시 형 변환 규칙**

    * 정수형 연산 시 `byte`, `short`, `char` 타입은 자동으로 `int`로 변환되어 계산됩니다.
    * 서로 다른 타입의 연산은 **더 큰 범위의 타입**으로 자동 변환된 후 계산됩니다.

### 2.2. 실습 코드 (`TypeCasting.java`)

```java
package chap1_2;

public class TypeCasting {

    public static void main(String[] args) {

        // java는 타입이 다른 테이터의 연산을 지원하지 않음 (타입을 일치시킨 후 연산 수행)
        
        // ---------------------------------------------------------
        // 1. 암묵적 형 변환 (Implicit Casting)
        // ---------------------------------------------------------
        byte a = 100;
        int b = a; // 암묵적 형 변환 (byte -> int) int가 더 크기 때문에 가능
        System.out.println(b);

        // ---------------------------------------------------------
        // 2. 명시적 형 변환 (Explicit Casting)
        // ---------------------------------------------------------
        int c = 1000;
        // 1000을 byte(-128~127)에 넣으면 비트가 잘려나가 엉뚱한 값(-24)이 됨 (Overflow)
        byte d = (byte) c; // int: 4 -> byte: 1
        // 명시적 형 변환 - 데이터 손실이 발생할 수 있음
        System.out.println(d);

        /**
         * [요약]
         * 암묵적(묵시적) 형 변환 -> upcasting (promotion) : 안전함
         * 명시적 형 변환 -> downcasting (demotion) : 데이터 손실 주의
         */


        // ---------------------------------------------------------
        // 3. 연산 시 자동 형 변환
        // ---------------------------------------------------------
        
        // 타입이 다른 데이터끼리의 연산은
        // 암묵적 형변환에 의해 작은 데이터가 큰 데이터로 변환됨

        int v = 91;
        double z = 6.6;
        // int(v)가 double로 변환된 후 91.0 + 6.6 계산 수행
        double result = v + z; 

        // char는 내부적으로 정수(유니코드)이므로 연산 가능
        int result2 = 'A' + v; // 'A'(65) + 91
        System.out.println("result2 = " + result2);

        // [주의] 나눗셈 연산
        int h = 5;
        // 정수/정수 = 정수이므로, 소수점을 얻으려면 하나를 double로 캐스팅해야 함
        double result3 = 27 / (double) h; 
        System.out.println("result3 = " + result3);

        // ---------------------------------------------------------
        // 4. int보다 작은 타입의 연산
        // ---------------------------------------------------------
        
        // int보다 작은 데이터 (char, short, byte) 들은
        // 연산 결과가 무조건 int다 (JVM의 피연산자 스택이 4byte 단위로 처리하기 때문)
        byte b1 = 100;
        byte b2 = 70;
        // byte result4 = b1 + b2; // 컴파일 에러 발생 (결과가 int임)
        int result4 = (b1 + b2);

        // char + char = int
        System.out.println('A' + 'C'); // 65 + 67 = 132 출력
    }
}
```

## 3\. 표준 입출력 (Standard I/O)

자바에서는 `System.out`을 통해 화면에 출력하고, `System.in`과 `Scanner` 클래스를 통해 사용자 입력을 받습니다.

### 3.1. 주요 메서드 및 포맷 지정자

**출력 메서드**
| 메서드 | 설명 | 특징 |
| :-- | :-- | :-- |
| `println()` | 출력 후 줄 바꿈 | 가장 많이 사용됨 |
| `print()` | 출력 후 줄 바꿈 없음 | 이어쓰기 할 때 사용 |
| `printf()` | 형식(Format)에 맞춰 출력 | `%d`, `%s` 등의 지정자 사용 |

**포맷 지정자 (Format Specifier)**
| 기호 | 설명 | 예시 |
| :-- | :-- | :-- |
| `%d` | 10진수 정수 (Decimal) | `printf("%d", 10);` |
| `%s` | 문자열 (String) | `printf("%s", "Hello");` |
| `%c` | 문자 1개 (Character) | `printf("%c", 'A');` |
| `%f` | 실수 (Float) | `printf("%.2f", 3.14159);` (소수점 2자리) |
| `%n` | 줄 바꿈 (New line) | `printf("끝%n");` |

### 3.2. 실습 코드 (`StandardIO.java`)

```java
package chap1_2;

import java.io.IOException;
import java.util.Scanner;

public class StandardIO {

    public static void main(String[] args) throws IOException {

        // ---------------------------------------------------------
        // 1. 자바의 표준 출력
        // ---------------------------------------------------------
        System.out.println("안녕");       // 줄바꿈 포함
        System.out.print("메롱\n");       // 줄바꿈 없음 (\n으로 수동 줄바꿈)

        int month = 6;
        int day = 6;
        
        // printf를 사용하면 문자열 결합(+) 없이 깔끔하게 포맷팅 가능
        System.out.printf("오늘은 %d월 %d일입니다.\n", month, day);
        System.out.println("하하호호");
        
        /*
            [포맷 지정자]
            %d -> 10진수 정수
            %s -> 문자열
            %c -> 문자 하나
            %f -> 실수
         */

        // [참고] 문자열 포맷팅 메서드
        
        // 자바 15 부터 가능: "문자열".formatted()
        String message = "오늘은 %d월 %d일 입니다.".formatted(month, day);
        System.out.println("message = " + message);

        // 자바 5부터 가능: String.format() (static 메서드)
        String message2 = String.format("오늘은 %d월 %d일입니다.", month, day);


        // ---------------------------------------------------------
        // 2. 표준 입력 (Scanner)
        // ---------------------------------------------------------
        
        // System.in: 키보드 입력 스트림
        Scanner scanner = new Scanner(System.in);

        System.out.print("이름:");
        String name = scanner.nextLine(); // 입력커서 생성, 엔터 칠 때까지의 문자열을 읽음

        System.out.print("나이:");
        // nextInt() 대신 nextLine()으로 받고 parseInt()를 쓰는 것이 버퍼 처리에 안전함
        int age = Integer.parseInt(scanner.nextLine()); 

        System.out.println("name = " + name);
        System.out.println("age = " + age);
        
        // 리소스 해제 (권장)
        scanner.close();
    }
}
```

-----

### **[Tip] `Scanner` 사용 시 주의사항**

`nextInt()`와 같은 메서드를 사용하고 나서 `nextLine()`을 사용하면, `nextInt()`가 숫자만 가져가고 남겨둔 \*\*엔터(개행문자)\*\*를 `nextLine()`이 읽어버려 입력을 건너뛰는 문제가 발생할 수 있습니다.

> **해결책:** 위 코드처럼 모든 입력을 `nextLine()`으로 받아 문자열로 처리한 뒤, 숫자가 필요한 경우 `Integer.parseInt()` 등을 통해 변환하는 방식이 가장 깔끔합니다.
