## 1\. 배열의 기초 (Array Basic)

배열은 **같은 타입**의 데이터를 연속된 메모리 공간에 저장하는 자료구조입니다.

### 1.1. 핵심 특징

1.  **동종 모음 구조**: 선언된 타입과 다른 타입의 데이터는 저장할 수 없습니다.
2.  **크기 불변**: 한 번 생성(`new`)되면 그 길이를 늘리거나 줄일 수 없습니다.
3.  **메모리 구조**:
    * 배열 **변수**(참조값)는 **Stack** 영역에 생성됩니다.
    * 실제 데이터가 담긴 **배열 객체**는 **Heap** 영역에 생성됩니다.

### 1.2. 배열의 초기화 기본값 (Default Values)

`new` 키워드로 배열을 생성하면, 따로 값을 넣지 않아도 타입별 기본값으로 자동 초기화됩니다.

| 데이터 타입 | 기본값 | 비고 |
| :-- | :-- | :-- |
| `byte`, `short`, `int` | `0` | 정수형 |
| `long` | `0L` | 정수형 |
| `float` | `0.0F` | 실수형 |
| `double` | `0.0` | 실수형 |
| `boolean` | `false` | 논리형 |
| `char` | `\u0000` (공백) | 문자형 |
| **참조 타입** (`String` 등) | `null` | 주소 없음 |

### 1.3. 실습 코드 (`ArrayBasic.java`)

```java
package chap1_2.array;

import java.util.Arrays;

public class ArrayBasic {

    public static void main(String[] args) {

        // 배열: 1.동종모음 구조 ( 같은 타입끼리만 저장 가능)
        //       2. 생성시 크기가 불변함 ( 값을 안넣으면 기본값 초기화)

        // ---------------------------------------------------------
        // 1. 배열의 생성 단계
        // ---------------------------------------------------------
        
        // 1) 배열 변수를 선언 (스택에 변수 공간 확보)
        int[] numbers;
        
        // 2) 배열을 생성 (힙에 실제 데이터 저장 공간 확보 - 5칸)
        numbers = new int[5];
        
        // 3) 배열을 초기화 (값 저장)
        numbers[0] = 50;
        numbers[1] = 77;
        numbers[2] = (int) 66.7; // 형 변환 후 저장
        numbers[3] = numbers[0] * 2;
        numbers[4] = 99;

        // 참조값(주소) 출력 (예: [I@references...)
        System.out.println("numbers = " + numbers); 
        // 배열 내부 값 확인을 위한 유틸리티 메서드
        System.out.println(Arrays.toString(numbers));

        // 배열 길이 확인 (length는 프로퍼티)
        System.out.println(numbers.length);


        // ---------------------------------------------------------
        // 2. 배열 순회 (Iteration)
        // ---------------------------------------------------------
        System.out.println("========================");

        // 1) 일반 for문 (인덱스 제어 가능)
        for (int i = 0; i < numbers.length; i++) {
            System.out.println(numbers[i]);
        }

        System.out.println("========================");

        // 2) 향상된 for문 (Enhanced for loop) - 전체 순회 전용
        for (int number : numbers) {
            System.out.println("number = " + number);
        }

        System.out.println("========================");
        
        // 3) 스트림 (Stream API) - 람다식 활용
        Arrays.stream(numbers).forEach(number -> System.out.println("number = " + number));

        System.out.println("========================");


        // ---------------------------------------------------------
        // 3. 배열 선언과 생성을 동시에 (단축 문법)
        // ---------------------------------------------------------
        
        // 정석 문법: String[] pets = new String[] {"가", "나", ...};

        // 변수를 선언할 때만 new Type[] 생략 가능
        String[] pets = {"가", "<UNK>", "<UNK>", "<UNK>"};
        
        // 이미 선언된 변수에 재할당 할 때는 new Type[] 생략 불가!
        pets = new String[]{"메롱","메롱"};

        System.out.println(Arrays.toString(pets));

        // 메서드 파라미터로 넘길 때도 생략 불가
        foo(new String[]{"하하","호호"});

        System.out.println("========================");


        // ---------------------------------------------------------
        // 4. 배열의 기본값 확인
        // ---------------------------------------------------------
        /*
                # 배열의 기본값
                자바의 배열은 생성되는 순간 해당 공간에 기본 값들을 채워넣음
         */

        byte[] bytes = new byte[5]; // 0으로 초기화
        System.out.println(Arrays.toString(bytes));

        double[] darry = new double[5]; // 0.0으로 초기화
        System.out.println(Arrays.toString(darry));

        // 기본타입 ( 정수, 실수, 논리, 문자-char)
        // 나머지는 참조타입(주소를 저장하는 변수 - 포인터)
        String[] sArr = new String[5]; // null로 초기화
        System.out.println(Arrays.toString(sArr));
    }

    static void foo(String[] sArr){

    }
}
```

## 2\. 배열의 복사 (Array Copy)

배열 변수끼리 대입 연산(`=`)을 하면 **주소값만 복사**됩니다(Shallow Copy). 원본 배열을 보존하면서 사본을 수정하려면 **새로운 배열을 생성하여 값을 옮겨 담아야** 합니다.

### 2.1. 주요 메서드

| 클래스 | 메서드 | 설명 |
| :-- | :-- | :-- |
| `Arrays` | `toString(arr)` | 배열 내용을 문자열로 반환 |
| `Arrays` | `copyOf(original, newLength)` | 배열을 새로운 길이만큼 복사해서 새 배열 반환 |

### 2.2. 실습 코드 (`ArrayCopy.java`)

```java
package chap1_2.array;

import java.util.Arrays;

// 배열 복사 알고리즘
public class ArrayCopy {

    public static void main(String[] args) {

        String[] pets = {"멍멍이", "야옹이", "짹짹이"};

        // [잘못된 복사] 
        // String[] petsCopy = pets; // 주소 복사 (같은 객체를 바라봄)

        // [수동 복사]
        // String [] petsCopy = new String[pets.length]; // 배열 객체 생성
        // for (int i = 0; i < pets.length ; i++) {
        //    petsCopy[i] = pets[i]; // 값 하나씩 옮기기
        // }

        // [Arrays.copyOf 이용 복사] - 가장 간편함
        // 내부적으로 새로운 배열을 생성하고 값을 복사해서 리턴해줌
        String[] petsCopy = Arrays.copyOf(pets, pets.length);

        // 사본 수정
        petsCopy[1] = " 어흥이";

        System.out.println("원본 주소: " + pets);
        System.out.println("사본 주소: " + petsCopy); // 주소가 다름을 확인해야 함
        
        // 원본은 유지되고 사본만 변경되었는지 확인
        System.out.println("원본: " + Arrays.toString(pets)); 
        System.out.println("사본: " + Arrays.toString(petsCopy));
    }

}
```

## 3\. 배열 요소 추가 알고리즘 (Array Push)

자바 배열은 크기가 고정되어 있으므로, 데이터를 추가(`push`)하기 위해서는 **더 큰 배열을 생성하고 이사(Copy)가는 과정**이 필요합니다.

### 3.1. 알고리즘 단계

1.  기존 배열보다 **크기가 1 큰 새로운 배열**을 생성한다.
2.  기존 배열의 모든 데이터를 새 배열로 **복사**한다.
3.  새 배열의 **마지막 칸**에 추가할 데이터를 넣는다.
4.  기존 배열 변수가 **새 배열을 가리키도록 주소를 변경**한다.
5.  (옵션) 임시 배열 변수는 null 처리하거나 범위를 벗어나게 하여 GC(Garbage Collector) 대상이 되게 한다.

### 3.2. 실습 코드 (`ArrayPush.java`)

```java
package chap1_2.array;


import java.util.Arrays;

// 데이터 추가 알고리즘
public class ArrayPush {

    static int[] numbers = {10, 20, 30, 40};

    public static void main(String[] args) {

        int newNumber = 50;

        // -------------------------------------------------
        // Push 알고리즘 상세 구현 (Manual)
        // -------------------------------------------------
        
        // 1. 기존 배열 사이즈보다 한 칸 더 큰 배열 생성
        int[] tempArray = new int[numbers.length + 1];

        // 2. 원본배열의 값들을 새 배열로 복사
        for (int i = 0; i <numbers.length ; i++) {
            tempArray[i] = numbers[i];
        }

        // 3. 마지막 인덱스에 새 값 저장
        tempArray[tempArray.length -1] = newNumber;

        // 4. 주소값 이전 (원본 변수가 새 배열을 가리키게 함)
        numbers = tempArray;
        tempArray = null; // 임시 변수 연결 끊기

        
        // -------------------------------------------------
        // 메서드를 이용한 추가
        // -------------------------------------------------
        push(numbers, 90);
        push(numbers, 100);
        push(numbers, 110);


        System.out.println(Arrays.toString(numbers));
        // tempArray는 null 처리되었으므로 출력 불가 (주석 처리 된 셈)
        System.out.println(Arrays.toString(tempArray)); 

    }

    // 배열 추가 로직을 메서드로 모듈화
    static void push(int[] arr, int newData){
        // copyOf()를 쓰면 [배열생성 + 복사]를 한 번에 처리
        arr = Arrays.copyOf(arr, arr.length +1);
        arr[arr.length -1] = newData;

        // 정적 변수 numbers 업데이트
        numbers = arr;
    }
}
```
